Test a lab-slot booking app, and write defects somebody can actually fix
CareerSwami - Software Testing - Project 1 starter kit

WHAT THIS IS
Everything you need to start Project 1. Read the project brief PDF first -
this kit is the data and the blank forms it refers to.

Write a test plan and test cases from the requirements note, execute them against the eight behaviours, and file the ones that are genuinely defects with steps, evidence and a severity you can defend.

HOW TO USE IT
1. Read the brief PDF, then data/requirements.md. Nothing else yet.
2. Fill templates/test-plan.csv - write the out-of-scope rows first.
3. Write templates/test-cases.csv from the four rules, before you run
   anything.
4. Run the cases against local_mock.py (Python 3, no installs):
     python local_mock.py
   Type "help" inside it for the commands.
5. Record every case in templates/execution-log.csv, then file genuine
   failures in templates/defect-register.csv.
6. Record every claim in evidence-log.csv with the evidence behind it.

RULES
Everything here is fictional and runs on your own machine. Do not test any
system you do not own, do not use real student data or real email addresses,
and do not attempt load or security testing.

HONESTY
All data here is fictional. Use fictional organisations throughout. Never
invent interviews, users, tests or results. Credit anything you reused and
disclose AI assistance, including what you checked yourself. Never upload
identity documents, real customer records or credentials.
